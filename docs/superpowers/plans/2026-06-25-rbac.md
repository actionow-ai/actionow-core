# RBAC v1 (tenant-org multi-seat) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add tenant-org RBAC — a tenant can have a **tenant admin** (full `/app` control) and read-only **tenant members**, under the unchanged platform **system admin**.

**Architecture:** Additive `user.tenant_role` (nullable, CHECK), **DB-resolved in `ConsoleGuard`** (never in the JWT). A new `@TenantAdmin` guard returns 403 for members on the administrative console writes; new `/console/users` CRUD lets a tenant admin manage sub-users (plain USER rows, `role='user'` + `tenant_role='member'`). Audit captures `meta.actor_tenant_role`. The `/app` UI gates writes on `tenant_role` from `/console/me` and adds a Members page.

**Tech Stack:** NestJS (apps/api), drizzle/postgres (packages/db), zod contracts (packages/contracts), Vite/React (apps/web). Tests: vitest; db uses `@testcontainers/postgresql` int tests; commitlint wants lowercase imperative subjects.

**Spec:** `docs/superpowers/specs/2026-06-25-rbac-design.md`. Branch: `feat/rbac` (already created; the spec is committed there).

**Conventions seen in this repo (follow them):**

- After a `packages/db` schema edit: `pnpm --filter @actionow/db db:generate` (writes `packages/db/drizzle/00NN_*.sql` + meta), then `pnpm --filter @actionow/db db:migrate` against the dev DB.
- After a `packages/contracts` view/DTO change: `pnpm --filter @actionow/contracts build && pnpm --filter @actionow/contracts gen:openapi && pnpm --filter @actionow/sdk gen && pnpm --filter @actionow/sdk build`.
- Admin/console routes NOT in the SDK path set are consumed in the web via `rawClient` (see `apps/web/src/lib/api/admin.ts` precedent); `/console/users` is one of those.
- Build the API to dist + restart for live checks: `HTTP_EGRESS=curl node --env-file=.env --import tsx apps/api/dist/main.js` (port 3000). Web dev: preview_start("web-dev") :5173. Admin login: `admin@actionow.local` / `actionow-dev-password`.
- Money/ids: never log a created password/plaintext.

```ts
/** Set a tenant user's status (tenant-scoped); undefined when no row matched. */
export async function updateUserStatus(
  db: DbOrTx,
  tenantId: string,
  id: string,
  status: string,
): Promise<UserRecord | undefined> {
  const rows = await db
    .update(user)
    .set({ status, updatedAt: new Date() })
    .where(and(eq(user.id, id), eq(user.tenantId, tenantId), eq(user.role, 'user')))
    .returning(USER_COLUMNS);
  return rows[0];
}

/** Promote/demote a tenant user (tenant-scoped); undefined when no row matched. */
export async function updateUserTenantRole(
  db: DbOrTx,

  id: string,

    .where(and(eq(user.id, id), eq(user.tenantId, tenantId), eq(user.role, 'user')))
    .returning(USER_COLUMNS);
  return rows[0];
}
```

```ts
import { type CanActivate, type ExecutionContext, Injectable } from '@nestjs/common';
import { engineForbidden, engineUnauthorized } from '../common/errors.js';
import type { ConsoleRequest } from './console.guard.js';

/**
 * Runs AFTER {@link ConsoleGuard} on tenant-admin-only console routes: requires
 * `req.console.tenantRole === 'admin'`, else 403. A tenant member hits this.
 */
@Injectable()
export class TenantAdminGuard implements CanActivate {
  canActivate(context: ExecutionContext): boolean {
    const req = context.switchToHttp().getRequest<ConsoleRequest>();
    if (req.console === undefined) throw engineUnauthorized('request is not authenticated');
    if (req.console.tenantRole !== 'admin') {
      throw engineForbidden('tenant admin role required');
    }
    return true;
  }
}
```
