# P1a — Codex (ChatGPT) OAuth reverse-proxy channel — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use `- [ ]` checkboxes. TDD always: failing test → see it fail → minimal code → see it pass → commit.

**Goal:** Let the self-hosting operator use **their own paid ChatGPT/Codex subscription** as an Actionow upstream channel — a `codex-oauth` `providerType` that attaches the operator's OAuth token + the first-party Codex headers and relays chat to `chatgpt.com/backend-api/codex/responses` (OpenAI **Responses** shape), with encrypted-at-rest token storage and auto-refresh. Built on the merged F0 (encrypted secrets), P0a (routing/cooldown), and the llm-protocol/adapter split.

**Architecture:** A provider-agnostic OAuth credential scaffold (an `oauth_session` table encrypted via F0's AES-GCM; `resolveSecretRef` gains an `oauth` branch returning a LIVE access token, lazily refreshed) + a BullMQ refresh sweep + a `codex-oauth` adapter that hand-rolls IR↔OpenAI-Responses translation and the Codex transport/impersonation + admin acquisition (paste-auth-json first, server-side loopback PKCE login second) + multi-account = N `oauth_session` rows = N channels routed by P0a.

**Tech Stack:** TS (NodeNext ESM), Drizzle + drizzle-kit, NestJS 11, BullMQ, zod, vitest + Testcontainers. Money is bigint µcredits. Crypto via `node:crypto` (reuse `packages/db/src/crypto.ts`). Strict ESLint (no `any`, `exactOptionalPropertyTypes`, `consistent-type-imports`).

## Decisions (user-approved)

- **Codex first** (the user's own paid ChatGPT/Codex subscription; maximize their purchased quota). Gemini/Claude OAuth follow the same scaffold later.
- **Impersonation: yes, application-layer first-party headers** (User-Agent `codex_cli_rs/…`, `Originator: codex_cli_rs`, `Chatgpt-Account-Id`, `OpenAI-Beta: responses=experimental`, the Responses `instructions` carrying the system prompt) — required for the private `chatgpt.com` backend to accept the request. This is the operator using THEIR OWN account; opt-in, BYO, ToS-acknowledged.
- **NOT done:** JA3/uTLS TLS-fingerprint spoofing (impractical in Node + deepest evasion layer); anything oriented to farming/abusing OTHERS' accounts. If the upstream blocks on TLS fingerprint, surface it to the operator — do not escalate.
- **Acquisition:** BOTH paste-auth-json (ship first) AND server-side loopback PKCE login; **multiple accounts** supported (N oauth_session rows → N channels, P0a rotates).
- **Guardrails:** off by default behind `ENABLE_OAUTH_CHANNELS`; `POST /admin/oauth-sessions` requires `acknowledgeUpstreamTos: true`; tokens encrypted; `usage_log`/admin always show `provider_type='codex-oauth'`.

## Source-grounded reference (from CLIProxyAPI + sub2api + OpenAI well-known; H=verbatim-in-source)

- **OAuth (H):** client_id `app_EMoamEEZ73f0CkXaXp7hrann`; authorize `https://auth.openai.com/oauth/authorize` (params `response_type=code,redirect_uri,scope,state,code_challenge,code_challenge_method=S256,prompt=login,id_token_add_organizations=true,codex_cli_simplified_flow=true`); token `https://auth.openai.com/oauth/token` (form-encoded); redirect `http://localhost:1455/auth/callback`; scopes authorize=`openid email profile offline_access`, refresh narrows to `openid profile email`; PKCE S256 (64-byte hex verifier). Token resp JSON `{access_token, refresh_token, id_token, token_type, expires_in}`. **account_id** = `id_token` JWT claim `["https://api.openai.com/auth"].chatgpt_account_id` (base64-decode the claims segment; signature NOT verified). email = JWT `email`; plan = `chatgpt_plan_type`. Refresh body form `{client_id, grant_type:refresh_token, refresh_token, scope:"openid profile email"}`; error containing `refresh_token_reused` → terminal (needs_reauth).
- **Upstream (H):** `POST https://chatgpt.com/backend-api/codex/responses` (Responses shape; compact `/responses/compact`). Auth `Authorization: Bearer <access_token>`. Headers: `User-Agent: codex_cli_rs/0.125.0 (Ubuntu 22.4.0; x86_64) xterm-256color`; `Originator: codex_cli_rs`; `Chatgpt-Account-Id: <account_id>`; `OpenAI-Beta: responses=experimental`; `version: 0.125.0`; `Accept: text/event-stream` (stream) / `application/json`; `session_id`/`conversation_id` (stable per conversation). Request transform: Chat→Responses, force `store=false`, `input` MUST be a list (not a string), extract `role:system` messages into top-level `instructions` (the upstream REJECTS a system role), add `include:["reasoning.encrypted_content"]` when reasoning present, model map (`gpt-5*`/`codex-*` → the codex model id). Response is Responses-API SSE events.

# Sub-track S1 — Provider-agnostic OAuth credential scaffold

## Task S1.1 — `oauth_session` schema + migration

**Files:** `packages/db/src/schema/oauth.ts` (new); `packages/db/src/schema/index.ts` (export); migration.

- [ ] Create the table (1:1 with a `secret_ref`, mirroring `secret_material`):

```ts
import { pgTable, text, timestamp, uuid } from 'drizzle-orm/pg-core';
import { secretRef } from './catalog.js';

/**
 * A rotating OAuth session for a `provider='oauth'` secret_ref (P1a). Access +
 * refresh tokens are AES-256-GCM ciphertext (F0 crypto); never plaintext. 1:1
 * with its secret_ref. Mutable (rotated on refresh) — unlike the immutable
 * secret_material blob, hence its own table.
 */
export const oauthSession = pgTable('oauth_session', {
  secretRefId: uuid('secret_ref_id')
    .primaryKey()
    .references(() => secretRef.id),
  providerKind: text('provider_kind').notNull(), // 'codex-oauth' | (later) 'claude-oauth' | 'gemini-oauth'
  accountLabel: text('account_label'), // email / plan — operator UI only, never a secret
  accountId: text('account_id'), // chatgpt_account_id (codex) / project_id (gemini); not a secret
  accessEnc: text('access_enc').notNull(), // AES-GCM(access_token)
  refreshEnc: text('refresh_enc').notNull(), // AES-GCM(refresh_token)
  expiresAt: timestamp('expires_at', { withTimezone: true }),
  lastRefreshAt: timestamp('last_refresh_at', { withTimezone: true }),
  refreshLockAt: timestamp('refresh_lock_at', { withTimezone: true }), // DB singleflight guard
  status: text('status').notNull().default('active'), // 'active' | 'needs_reauth'
  updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
});
```

- [ ] Export from `schema/index.js`. `pnpm --filter @actionow/db db:generate`. Confirm a new `00NN_*.sql` with `CREATE TABLE "oauth_session"` + FK. typecheck. Commit `feat(db): oauth_session table + migration`. (Presence proven by S1.2's int test.)
