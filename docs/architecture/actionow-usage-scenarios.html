一套平台，
四种赚钱方式。

Actionow 是部署在公司内部的 AI 能力中台：对上对接各家大模型与媒体供应商，对下让多个 AI 产品接入。 它统一完成调用中继、用量计量、按量计费与记账——因此同一套系统，能直接支撑 B2B2C、B2B、B2C 与内部成本分摊四种商业模式。

场景一

四种使用场景

同一套引擎，靠两个开关组合出四种模式：是否给每个端用户单独建钱包，以及费用是否归因到具体用户。

01
B2B2C

公司自营产品，卖给消费者

公司自建一个对外的 AI 产品（=租户），它的付费用户消费 AI；平台按用量向产品方收成本，产品方赚差价。

资金路径

端用户 付零售价 $X→ 自营产品（租户） 充值批发价 $Y→ Actionow 平台 承担成本→ 上游 AI

技术映射：subject 子钱包（sub_account）/ ledger settle(subject_id) / 按 subject 绑定额度套餐 / 端用户自助门户 /member。

四种模式的核心差别，就在谁付钱给谁与钱包归属两列。

场景谁付钱给谁钱包归属平台 / 应用方收入适用对象
B2B2C 端用户→产品方（零售）；产品方→平台（批发） 每端用户独立钱包，或共享租户池 产品方赚零售-批发差价；平台收批发用量费 对外消费级 / 行业 AIGC 产品
B2B 合作企业→应用方（席位费）；应用方→平台（用量） 应用方共享账户（无端用户钱包） 应用方收席位/套餐费；平台收用量费 API 经销 / 企业集成 / 白标
