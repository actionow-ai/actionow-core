两种用法

按需选更轻的那种 —— 纯中转不需要 subjects,也不碰 /console 联邦。

A · 全模态模型中转站

一把租户级 ak_ key 指向 /v1,任意 OpenAI 兼容 SDK 跨 chat / 图 / 视频 / 音频 / embeddings / rerank 全模态调用 —— 路由 / fallback / 熔断 / 统一账单全含。不建 subject、不碰联邦。搭建:建租户 → 充值 → 铸 key → SDK 指过来。

1 key/v1 全模态零联邦

B · 基于 core 建应用

在 A 基础上,把你自己的端用户联邦为 subject —— 每用户 key、子钱包、每用户限额与消费归属 —— 把 core 能力藏在你的产品后转售。

subject 联邦子钱包每用户归属

A 是 B 机制的严格子集 —— 同样的 /v1 调用;B 只多一层每端用户身份。先用 A,需要每用户钱包 / 限额 / 归属时再上 B。

03

能力图

core 提供的能力域,以及复用矩阵——哪些能直接用、哪些你自建。

对话中继

OpenAI / Anthropic / Gemini 三方言,阻塞 + 流式(SSE)。

/v1/chat/completions/v1/messages/v1beta/...

媒体生成

图 / 视频 / 音频(TTS + 转写)。异步任务或 OpenAI 兼容便捷端点。

/v1/images/generations/v1/audio/speechtranscriptions

向量 / 检索

嵌入、重排、审核,按输入 token 计费。

/v1/embeddings/v1/rerank/v1/moderations

任务 / 编排

通用资源执行:blocking / stream / async-poll / async-callback + 任务轮询。

/v1/run/:id/v1/jobs/:id/stream · /cancel

路由与渠道

一个模型名可挂多渠道:自动分层 + 熔断 + 跨渠道 failover。要指定渠道用 X-Actionow-Route-Tag 头或 key↔路由分组(同步调用生效;异步 job 暂不钉选)。

X-Actionow-Route-Tagroute-groupfailover

文件存储

presign 上传 → confirm → 下载 URL,带配额;file_id 作为 run 的输入。

/v1/files/presign-upload/v1/files/:id/url

计费与额度

µcredit 账本(1 credit = 1e6 µcredit)· 租户池 + 每用户子钱包 · hold→settle · 治理限额。

/console/payments/intents/console/redeemlimit-plan

复用矩阵 — 直接用 vs 自建

core 提供,直接复用

  • 用户系统 — subject 身份 + Model-A 自助(读余额/用量 + 改资料/密码 + 自铸 ak_)
  • 积分系统 — 租户池 + 子钱包,hold→settle,µcredit
  • 充值系统 — 支付 intent + 卡密兑换 + 子钱包充值/守恒划转
  • 模型系统 — 兼容中继 + 路由/容错/计费 + GET /v1/models
  • 文件存储 — presign 上传/下载 + 配额

core 不管,你自建

  • 业务用户档案 / 权限 — 你的完整用户体系与角色
  • 产品 UX — 界面、交互、你的品牌
  • Prompt / 编排 — 你的 AI 逻辑与工作流
  • 领域数据 — core 不存业务数据,你只在自己库里存 core 的 ID

关键约束:端用户 member JWT 不能直连 /v1;AI 调用要经持 ak_ 的服务端,或让 member 自铸一把 ak_ 再用。

端点速查 + 铁律

1

双 client 隔离:控制面 JWT 仅服务端;数据面 ak_ 按端用户。

2

只存 ID,不镜像数据:存 subject_id / file_id / job_id,余额按需回源读。

3

钱是 µcredit 字符串:BigInt 解析,绝不 Number;expiresIn 是时长串。

4

按 retryable 重试:绝不重试 402/400;billed /v1/run 带 body idempotency_key,中继路由用 Idempotency-Key header(流式复用键会 400,换新键)。

5

webhook 原始字节验签 → 快速 ack → 回拉 GET /v1/jobs/:id。

6

end_user = external_id,不是 subject UUID;且只在 /v1/run 生效。

7

SDK 类型面窄:整个中继方言 + /console/subjects* 走裸 fetch。

8

Express 4 异步错误:包 asyncHandler + 错误中间件,否则一个 402 拖垮进程。
